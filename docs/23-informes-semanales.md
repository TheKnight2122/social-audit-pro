# Informes semanales

## Proposito

La carpeta `docs/semanales/` conserva un informe Word por semana para resumir las solicitudes atendidas, el desarrollo realizado, las validaciones, las evidencias visuales y el trabajo pendiente.

## Periodos iniciales

- `Informe-semanal-2026-09-07-al-13.docx`: linea base anterior al inicio formal. No registra actividad porque no existen commits ni informes verificables en ese periodo.
- `Informe-semanal-2026-09-14-al-20.docx`: resume la preparacion del repositorio, el MVP, las vistas independientes, el backend, la publicacion, la renovacion visual, YouTube OAuth y la documentacion Word.

## Regla de mantenimiento

Cada informe debe basarse en commits, archivos de `docs/avances/`, pruebas y evidencias reales. Si una semana no tiene actividad registrada, el documento debe indicarlo de forma explicita en lugar de inventar tareas.

Los informes no deben incluir nombres personales, contrasenas, tokens, credenciales, sesiones ni datos privados. Antes de versionarlos se deben renderizar e inspeccionar todas sus paginas.
