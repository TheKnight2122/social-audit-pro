# Desarrollo

## Lineamientos iniciales

- Trabajar con cambios pequenos y commits descriptivos.
- Mantener documentacion, pruebas y estado sincronizados con cada avance.
- No marcar funcionalidades como completadas si no fueron implementadas y probadas.
- Registrar problemas importantes en la documentacion de incidencias.
- Registrar decisiones tecnicas importantes mediante ADR.

## Flujo de trabajo recomendado

1. Revisar estado actual.
2. Elegir requisito o tarea concreta.
3. Implementar el cambio de forma acotada.
4. Ejecutar pruebas.
5. Actualizar documentacion.
6. Registrar avance.
7. Crear commit descriptivo.
8. Sincronizar con GitHub.
