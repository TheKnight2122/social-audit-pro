# Avance 006 - Publicacion continua en GitHub Pages

## Fecha

2026-09-15

## Objetivo

Mantener una demostracion publica sin fecha de vencimiento y actualizarla automaticamente con el desarrollo del proyecto.

## Trabajo realizado

- Flujo de GitHub Actions para construir la demostracion estatica.
- Publicacion automatica al enviar cambios a la rama `main`.
- Ejecucion manual disponible desde GitHub Actions.
- Separacion entre la demostracion publica y el sistema local con backend.

## Resultado esperado

Cada avance confirmado y subido al repositorio actualiza GitHub Pages sin modificar el funcionamiento local de la API, SQLite, autenticacion o reportes PDF.
