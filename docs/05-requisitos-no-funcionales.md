# Requisitos no funcionales

- RNF-001 - El sistema debe priorizar claridad y utilidad empresarial sobre cantidad de graficos.
- RNF-002 - La interfaz debe ser moderna, limpia, responsive y orientada a software empresarial.
- RNF-003 - El sistema debe mantener modularidad para agregar nuevas redes sociales sin reescrituras mayores.
- RNF-004 - Las formulas de metricas calculadas deben estar documentadas.
- RNF-005 - El sistema no debe presentar hipotesis como hechos.
- RNF-006 - Los tokens y credenciales deben almacenarse de forma segura y nunca versionarse.
- RNF-007 - El sistema debe validar entradas y manejar errores de manera segura.
- RNF-008 - El sistema debe registrar actividad relevante para auditoria.
- RNF-009 - El sistema debe manejar limites de API y errores de sincronizacion.
- RNF-010 - La base de datos debe evitar duplicidad y conservar historicos.
- RNF-011 - Los reportes deben utilizar lenguaje profesional y comprensible.
- RNF-012 - El proyecto debe mantener documentacion, pruebas, avances, changelog y trazabilidad actualizados.
