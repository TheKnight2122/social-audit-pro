# Alcance

## Incluido

- Dashboard ejecutivo con KPIs, salud de cuenta, tendencias y recomendaciones.
- Auditoria integral de perfiles.
- Analisis de metricas, contenido, audiencia, engagement y crecimiento.
- Comparativas por red social, cuenta, periodo, formato, campaña y publicacion.
- Deteccion de anomalias.
- Ranking de mejores y peores publicaciones.
- Recomendaciones automaticas priorizadas.
- Reportes profesionales.
- Gestion de usuarios y roles.
- Arquitectura preparada para APIs oficiales de redes sociales.
- Registro de sincronizaciones y actividad.

## Excluido

- Publicacion automatica.
- Programacion automatica de publicaciones.
- Publicacion masiva.
- Bots que publiquen contenido.
- Calendario con ejecucion automatica.
- Almacenamiento directo de contrasenas de redes sociales.

## Alcance del MVP actual

El MVP implementa una interfaz web con datos demo, calculos locales, dashboard, auditoria, analisis de publicaciones, anomalias, recomendaciones y reporte textual. No incluye backend, base de datos real ni integraciones oficiales todavia.
