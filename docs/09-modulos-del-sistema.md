# Modulos del sistema

## Modulos previstos

- Dashboard: vista ejecutiva de rendimiento.
- Auditoria: puntuacion de salud y evaluacion por dimensiones.
- Metricas: analisis detallado de comunidad, alcance, impresiones, engagement, contenido, video y conversion.
- Contenido: tabla de publicaciones, filtros, ordenamiento y rankings.
- Audiencia: datos demograficos y comportamiento cuando la API los proporcione.
- Comparativas: analisis entre plataformas, periodos, cuentas, campañas y formatos.
- Insights: deteccion de patrones, tendencias y anomalias.
- Recomendaciones: acciones priorizadas con evidencia e impacto.
- Reportes: generacion y consulta de informes.
- Integraciones: conexion con APIs oficiales y control de sincronizaciones.
- Configuracion: usuarios, roles, permisos y parametros.

## Modulos implementados en MVP

- Dashboard parcial.
- Auditoria parcial.
- Contenido parcial.
- Insights parcial.
- Recomendaciones parcial.
- Reporte textual parcial.
