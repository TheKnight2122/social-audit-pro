# Manual de instalacion

## Requisitos previos

- Node.js 20 o superior.
- npm.
- Navegador moderno.

## Pasos de instalacion

1. Clonar o abrir el repositorio.
2. Ejecutar:

```bash
npm install
```

3. Iniciar el servidor local:

```bash
npm start
```

4. Abrir:

```text
http://localhost:4173
```

## Verificacion

Ejecutar:

```bash
npm test
```

Las pruebas deben finalizar correctamente.
